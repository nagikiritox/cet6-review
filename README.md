# LAGOM · CET-6 学习空间

一个纯静态的六级备考网站。没有后端、不需要安装依赖，打开 `index.html` 就能用。

设计取意瑞典语 **lagom**（不多不少，刚刚好）：暖白纸感底色、几何无衬线字体、大圆角与克制的配色，跟随系统深浅色，也可以手动切换。

## 打开方式

最简单：双击 `index.html`。

如果浏览器对 `file://` 下的音频或存储有限制，可以在项目目录启动一个本地静态服务：

```powershell
cd Y:\Code-room\DSH\cet6-review
python -m http.server 8000
```

然后访问 <http://127.0.0.1:8000>。

所有学习数据保存在浏览器的 `localStorage` 中，换浏览器或清空站点数据后会重新开始。

## 功能地图

### 刷题

- **真题模拟**：2 套 130 分钟全真结构模拟卷，写作 + 听力 + 阅读 + 翻译，交卷后按 710 分制估分，主观题可自评。
- **套题训练**：3 套 45 分钟轻量套卷，按 100 分制计分，适合保持手感。
- **专项练习**：听力、阅读、翻译、写作四类，共 18 组材料；可整套开始，也可单组训练。
- **听力音频**：18 段原创听力材料，`assets/audio/` 下为真实 MP3 文件，支持进度拖动、重播、原文在提交后解锁。
- 答题卡、标记题目、倒计时、自动交卷、键盘快捷键（1-4 选择、← → 切题、F 标记）。
- 交卷后生成学习报告：估分、正确率、分项得分、错题解析、再练入口。

### 背单词

- 120 个 CET-6 核心词，含音标、词性、释义、例句与翻译。
- 专注翻卡：先回想，再显示释义，选择「不认识 / 有点模糊 / 认识」。
- 记录已学、已掌握、错词、生词标记；支持搜索、按状态筛选、加载更多。
- 今日目标、连续学习天数、最近 14 天背诵记录。
- 单词发音使用浏览器内置 `SpeechSynthesis`（英语语音）。

### 我的数据

- **总览**：累计练习、完成题目、综合正确率、背词进度、分数趋势、题型强弱、题型雷达、错题分布、12 周学习热力图、最近练习。
- **错题本**：按模块筛选，展示你的答案 / 正确答案 / 解析；可标记已掌握、重新加入、开始错题重练。
- **练习记录**：按月份分组的全部练习，可回看每次报告；支持导出 JSON 备份。
- 学习设置：每日背词量、目标分数、考试日期；可清空全部数据。

### 导入真实真题

「刷题 → 导入真题」支持导入你自己的真题题目和听力音频：

- 题目文件：`.json`、`.txt`、`.md`、`.pdf`。
- 听力文件：`.mp3`、`.wav`、`.m4a`、`.ogg`、`.aac`，可多选。
- 可选答案文件：答案与题目分开时，上传 `.txt` / `.md` / `.pdf` 答案文件。
- 解析后会先进入预览：检查题目数量、校验选项/答案、逐个绑定听力音频，再保存。
- 保存后成为一套独立的「导入真题」卷，支持计时、交卷、710 估分、主观题自评、错题本、分数趋势与题型统计。
- 导入内容保存在浏览器的 `IndexedDB` 中，不会上传到 GitHub；不同设备不共享。部署更新不会清空导入数据，但清理浏览器站点数据会。
- PDF 仅支持带文字层的文本型文件；扫描版 PDF 需要先 OCR。PDF 版式千差万别，选词填空、长篇匹配等部分可能无法完整识别，可以在预览中编辑提取文本后重新解析。
- 内置解析包：站点已内置 **2024 年 6 月六级第 1 套**的听力原文、55 道客观题答案与解析。上传同一版 PDF（+ 对应 MP3）时会自动识别并载入完整解析，不依赖外部 API；其他 PDF 仍走基础提取，不会自动生成答案和听力原文。
- 导入页提供 JSON 和 TXT 模板下载，也可以直接粘贴题目文本解析。


## 首次打开会看到示例数据

为了让数据主页一开始就有内容可看，第一次打开会生成一份**明确标注为「示例预览」**的记录。开始任意一次练习或背词后，示例会自动清除，换成你的真实记录；也可以点击页面上的「清除示例」立即清空。

## 内容说明

题目、听力原文、译文与范文均为**原创模拟内容**，用于备考练习，不包含真实六级真题原文。听力音频由系统语音合成生成，语速与音色适合精听和做题训练。

选择题展示时会对选项做一次确定性的乱序（答案与解析同步映射），避免正确答案长期固定在同一位置；每次刷新保持同一顺序，旧答题记录不受影响。

## 自定义

- 换题：按 `DATA_SPEC.md` 的字段结构修改 `data/units-*.js`，并在 `data/papers.js` 里引用单元 ID。
- 换词：修改 `data/words.js`，保持 `id` 唯一即可。
- 换主题色：在 `css/base.css` 的 `:root` 与 `:root[data-theme="dark"]` 中改 CSS 变量。
- 换字体：把 woff2 文件放进 `assets/fonts/`，修改 `base.css` 顶部的 `@font-face` 与 `--font-sans`。
